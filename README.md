
# 🚀 PlacementPilot – AI-Powered Placement Platform

An intelligent placement preparation platform designed to help students prepare for software engineering placements through coding practice, AI-powered mock interviews, and skill assessments.

## 🎯 Project Overview

PlacementPilot aims to provide students with a single platform to improve their technical knowledge, coding skills, problem-solving abilities, and interview confidence.

## ✨ Key Features

- AI-Powered Mock Interviews
- Technical Interview Questions
- Coding Practice and Assessment
- Skill Assessment
- Interview Performance Evaluation
- Student Progress Tracking

## 🛠️ Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **API Testing:** Postman
- **Version Control:** Git and GitHub
- **Containerization:** Docker

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Manu701970/AI_Powered_placement_platform.git
```

### 2. Open the Project

```bash
cd AI_Powered_placement_platform
```

### 3. Configure Environment Variables

Configure the backend environment variables using the provided `.env.example` file.

### 4. Configure MySQL

Create the required database and execute the SQL setup script from:

`backend/database/setup-local-mysql.sql`

### 5. Run the Backend

Open the backend folder and run:

```bash
mvn spring-boot:run
```

Follow the project's configuration for the required database credentials and environment variables.
